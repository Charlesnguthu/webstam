Privacy notice

How project inquiry information is handled on this website.

Information you submit

When you send a project inquiry, the name, work email, optional phone number, organization, and contact preference, selected service, optional budget and timeline, project summary, and consent are stored so authorized Webstam Technologies staff can review and respond. Do not include sensitive personal information.

Campaign information

If you arrive with standard UTM campaign parameters, short URL-safe values may be retained in the existing website session and associated with your inquiry. These values are internal, are not displayed publicly, and do not affect whether the form can be submitted. Arbitrary values are length-limited and filtered. For abuse prevention, the server uses the connecting IP temporarily as a hashed cache key that expires after one hour; the raw IP is not stored with inquiries.

Optional analytics

Google Analytics is disabled unless a measurement ID is configured and you choose Allow analytics. Declining keeps the analytics script unloaded. When enabled, the site records page views, enquiry success, consultation actions, and outbound profile clicks. It does not send enquiry names, email addresses, descriptions, campaign query strings, or other form contents. Your choice is stored in this browser's local storage.

Email notifications

If email notifications are configured, a notification may be sent to the company recipient. The email contains a notice that an inquiry was submitted and does not include the full inquiry description. The confirmation page says a notification was sent only when Django's send operation succeeds.

Retention and deletion

Inquiry data is private and visible only to authorized staff in Django administration. Staff should review enquiries periodically and delete records when they are no longer needed, subject to applicable legal, accounting, and contractual requirements. To delete a record, open Django admin → Contact → Inquiries, select the record, and use the delete action. Operators must also expire database backups according to the hosting backup policy; deletion from the live database does not immediately remove historical backups. No automatic retention period is configured.

Questions

Use the project inquiry form to ask about this notice. This is a general description of current website handling and should be reviewed by Webstam for applicable legal requirements and a specific retention schedule before launch.
